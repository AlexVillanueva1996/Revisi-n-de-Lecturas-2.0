# Corrector académico

## Instalador para Windows

Descargue [Corrector_Academico_Instalador.zip](ENTREGA/Corrector_Academico_Instalador.zip), extraiga su contenido y ejecute el `.exe`. En la página del archivo de GitHub, utilice **Download raw file** para guardarlo.

El instalador descarga y prepara Python, LibreOffice, Graphviz, Java, LanguageTool local y las bibliotecas necesarias. Requiere Internet durante la instalación; los documentos se procesan localmente después. Está compilado, pero no se ha ejecutado aún en un Windows real. Consulte las [instrucciones de entrega](ENTREGA/LEEME.md) y los [checksums](ENTREGA/SHA256SUMS.txt).

El programa, el lanzador de Windows y las instrucciones están en [Corrector_Academico](Corrector_Academico/README.md).

No se han proporcionado lecturas reales. El sistema incluye un generador de documentos sintéticos y pruebas de integración.
