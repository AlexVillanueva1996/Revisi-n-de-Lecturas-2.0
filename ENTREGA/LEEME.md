# Instalador de Corrector Académico

`Corrector_Academico_Instalador.zip` contiene el ejecutable Windows y sus instrucciones. Extraiga el ZIP y abra el `.exe` en Windows 10/11 x64.

El instalador descarga y configura Python, LibreOffice, Graphviz, Java, LanguageTool local y las bibliotecas Python. Necesita Internet durante la instalación. El procesamiento posterior de documentos es local.

`SHA256SUMS.txt` contiene los hashes de ambos archivos. El ZIP se ha abierto y comprobado; contiene el mismo ejecutable que se entrega por separado.

El instalador está compilado desde Linux. No se ha ejecutado todavía en un Windows real. Incluye comprobaciones funcionales en el destino y no marca la instalación como completada si estas fallan.

En GitHub, abra el ZIP y pulse **Download raw file**. Si el repositorio es privado, inicie sesión con una cuenta que tenga acceso.
